# 简易扫雷隐私政策

开发及运营主体：瑞士卷工作室

政策版本：7

## 游玩和本地存档

简易扫雷 Android 正式版在游玩前需要联网完成 TapTap 登录、实名认证和防沉迷检查。
游戏会在设备的应用私有存储中保存棋局，以便您在符合游玩条件时继续上局。您可以在系统设置中清除应用数据，或卸载游戏来删除本地棋局。

## TapTap 登录

您同意本政策后，游戏会初始化易玩（上海）网络科技有限公司提供的 TapSDK，完成 TapTap 账号授权并在本机维护登录状态。
游戏向 TapTap 请求基础账号信息权限（basic_info），该权限包含 OpenID 和 UnionID。本游戏以 OpenID 识别您在本游戏中的账号并发起合规认证。登录凭证由 TapSDK 在本机管理。

为提供登录及合规认证服务、保证设备兼容性和定位故障，TapSDK 可能处理系统版本、设备型号、CPU 信息、网络类型、Android ID 和设备内存信息，并使用 Android 网络权限访问 TapTap 服务。有关处理方式、保存期限和您的权利，请参阅 TapSDK 隐私政策（https://developer.taptap.cn/docs/v3/sdk/start/agreement/）。

## 实名认证和防沉迷

TapSDK 会根据您的账号状态引导您授权使用 TapTap 认证结果，或按其实名界面提示提交真实姓名和身份证件号码。实名信息由 TapTap 合规认证服务处理，游戏通过 SDK 获取是否可以游玩的结果。游戏不会在棋局存档、应用日志或自建服务中保存您的姓名、身份证件号码。

TapTap 会根据实名结果检查当前账号的可玩时段和时长。未完成认证或不符合游玩条件时，棋盘不可操作。若您的可玩时段或时长在对局中结束，游戏会保存棋局并返回限制页面。

## 排行榜

通过实名认证和防沉迷检查后，标准棋盘的通关用时会提交到 TapTap 游戏服务。TapTap 使用您的游戏内账号关联每张榜单的最好成绩，并向游戏中的其他玩家展示排行榜名次和用时。若网络异常，游戏会在本机按账号暂存待提交的最好用时，并在您再次通过合规检查或打开榜单时重试。

您可以在排行榜内选择授权 TapTap 公开资料权限（public_profile）。该权限包含 OpenID、UnionID、昵称和头像。游戏会将获授权的 TapTap 昵称和头像地址同步到 TapTap 游戏服务，供其他玩家在游戏排行榜中查看。查看榜单时，游戏从 TapTap 图片服务加载头像，并可能在运行期间临时缓存图片。跳过授权时仍可使用排行榜，榜单显示「匿名玩家」和默认头像。头像缺失或加载失败时也会显示默认头像。

## 游戏数据分析

您同意本政策并完成 TapTap 授权后，游戏会启用易玩（上海）网络科技有限公司提供的 TapDB 数据分析服务。我们使用该服务统计游戏活跃与留存、定位登录和实名检查中的问题，并了解玩家如何使用棋盘和排行榜。

游戏和 TapDB SDK 会向 TapDB 上报以下信息，用于上述数据分析目的。

- 游戏事件包括应用启动、登录和认证结果、进入棋盘、按钮点击、棋局开始与结束。事件属性包括登录失败的阶段及原因、进入棋盘的方式、棋盘工具、难度、是否为无猜模式、胜负、对局用时和上报时间。
- TapDB SDK 会自动从 TapTap 登录资料读取当前账号在本游戏中的 OpenID 并随事件上报，用于关联同一账号的事件。
- SDK 还会处理设备品牌和型号、CPU 架构、内存、存储容量、屏幕宽高、操作系统名称及版本、系统位数和语言、是否为模拟器、网络类型、运营商、游戏包名、应用版本和 SDK 版本。
- SDK 使用设备标识（如 Android ID 及其衍生标识）、安装标识、持久化标识、会话标识、事件标识和事件序号或索引，区分设备、安装和会话并标记事件。

有关服务提供方的数据处理及权利行使方式，请参阅 [TapSDK 隐私政策](https://developer.taptap.cn/docs/v3/sdk/start/agreement/)。

您可以通过「TapTap 账号」退出登录。棋局仍保存在本机。已同步的排行榜成绩和展示资料由 TapTap 游戏服务保存，您可通过下方联系方式申请处理。
